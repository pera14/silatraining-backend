# Contract changes

`packages/contracts` is the single source of truth for API shapes. During the parallel phase (agents A–D)
changes are **additive only**: new endpoints, new optional fields, new error codes. Never rename, remove or
tighten an existing field. Log every change here, newest first, and rebuild (`pnpm --filter @sila/contracts build`).

| Date       | Agent           | Change                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Why                                                                                                                                                                               |
| ---------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-01 | E (integration) | Parallel slots: `RULES.maxParallelSlots` (2); `TrainerSlot.parallel` (`boolean`, defaults to `false`); single-slot `CreateSlotsRequest` takes optional `parallel`; error code `PARALLEL_LIMIT` (409) added to `trainer.slots.create`; helper `peakConcurrency()` (shared by API cap, web hint and mocks). API env `MAX_PARALLEL_SLOTS` (default 2) is the authoritative cap. Migration `*_parallel_slots` adds `Slot.parallel` and limits `slot_no_overlap` to non-parallel slots. | Trainers need two clients at the same time (or offset by 30 min) without turning slots into group classes.                                                                        |
| 2026-10-01 | E (integration) | New endpoint `trainer.clients.sessions` `GET /trainer/clients/:id/sessions?scope=upcoming\|past` → `TrainerPractice[]` (404 for a foreign client). `RangeQuery` (`trainer.calendar`, `client.slots`) now states the API's existing limit of `RULES.maxRangeDays` (62) days.                                                                                                                                                                                                        | The trainer's client-detail Practices tab read a 190-day calendar window, which the real API rejects (400); the limit was enforced but not in the contract, so mocks accepted it. |
